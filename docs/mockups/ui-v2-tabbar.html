    Was ist ChartRunner?

    ChartRunner verwandelt echte Kursverläufe in eine Laufstrecke. Jede Kerze ist Boden, jeder Docht ein Hindernis. Wer den Chart lesen kann, läuft weiter.

    Spielen und Traden, getrennt

    Das Spiel läuft ohne Geld. Trades passieren nur im Terminal oder über einen Vorschlag aus dem Bot Term, und immer erst nach deiner Wallet-Signatur.

    Kein Agent und kein Bot kann ohne deine Signatur handeln. „orders“ in der Agent Bridge erlaubt nur Vorschläge.

    Die Rubriken

    Alles liegt im Balken oben: Home, Terminal, Intel, Token, Wallet, Bot Term, Profile, Docs und Settings. Taste / öffnet die Suche.
