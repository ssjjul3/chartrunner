# ChartRunner Public Boundary

ChartRunner is open where public adoption increases trust and gated where private operations create economic value.

## Public

- Playable browser prototype at `chartrunner.xyz/play/`.
- Landing page and public product docs.
- Devnet wallet handoff and public Anchor program source.
- High-level SDK contract: abilities route through `ChartRunnerSDK`; rendering does not issue orders.

## Gated

- Standalone SDK package until it is publish-ready.
- Generated SDK browser artifacts.
- Broker adapters, hosted agent transports, MCP servers, and bridge URLs.
- Premium bots, tuned strategies, backtests, replay corpora, private market-data pipelines, partner submissions, and monetization operations.

## Rule

Public code can prove the concept. Gated systems should compound the business: execution, data, automation, distribution, and premium intelligence.
